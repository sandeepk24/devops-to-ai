## What this phase will cover

Phase 06 is the end state: you design systems where **intent becomes infrastructure** — engineers describe outcomes, AI agents operate the platform within policy, and feedback loops keep everything improving.

**Topics planned:**

- **Intent-driven infrastructure** — "ensure payments API stays under 200ms p99" as input, not a 50-line Helm change
- **AI agents as operators** — agents that query metrics, read runbooks, propose actions, and execute with approval
- **Designing feedback loops** — human-in-the-loop, eval harnesses for agent decisions, audit everything
- **Building your own AI ops platform** — tying together observability, LLM serving, RAG over runbooks, and action APIs
- **The autonomous engineer mindset** — when to automate, when to stop, how to stay accountable

**Planned capstone (working title):** A minimal AI ops platform — natural-language ops queries, grounded answers from your runbooks, and gated actions (e.g. "scale this deployment" requires approval).
