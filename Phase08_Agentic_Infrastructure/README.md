# Phase 08 — Agentic Infrastructure

> **Status: 🔜 Coming soon**

Go beyond chatbots: tool-using ops agents that query metrics/logs, read runbooks, and propose actions — with approvals for anything that mutates prod.

**You'll learn (planned):** tool/function calling, allowlisted tools, RAG over runbooks, approval gates, eval suites, prompt-injection defenses.

**Planned capstone:** A gated ops agent (read-only investigate + approve-to-rollback) with a small eval set.
